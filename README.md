# ロシア語レッスン復習ダッシュボード (Russian Lesson Review App)

ロシア語レッスンの復習用インタラクティブ Web アプリケーションです。

## 主な機能
- **七夕テキスト超高密度解剖**: 全単語分解・文法構造・学びの派生・スピーキング模範対話
- **全テキスト音声再生**: Web Speech API によるクリアなロシア語発音（0.8x / 0.9x / 1.0x 速度切替）
- **文法実戦ドリル**: 即時正誤判定＆アナスタシア先生の指導ポイント解説つき
- **アクセント＆活用チートシート**: 交通移動動詞 `привозить / привезти` の完全対比表
- **Anki カード一覧**: レッスン復習カード全37枚のエクスプローラー
