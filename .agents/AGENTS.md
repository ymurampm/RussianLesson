# Anki Russian カード生成ルール (Project-Scoped Rules)

Anki のロシア語レッスンデッキ（デフォルト: `02.Russian::ロシア語レッスン2`）のカードを自動生成・更新する際のルールです。

## 1. 基本生成ポリシー

*   **対象フィールドと生成内容**:
    *   `English` フィールド: `Russian` フィールド（ロシア語）に対する正確な日本語訳（※`(不完了 / 完了)` などの体表示はここには含めず、必要に応じた格支配 `[+対格]` のみ残してシンプルにすること）。
    *   `memo` フィールド: 学習効果を高める HTML 装飾付きの解説。
*   **物理改行の排除とHTML改行の確保**:
    *   モバイルやPCでの表示崩れや意図しない余白（空行）の発生を防ぐため、実データのHTMLコード内からは物理的な改行コード（`\n`）をすべて排除し、1行のテキストとしてフラット化して登録すること。
    *   ただし、テキストが密着して視認性が低下するのを防ぐため、解説の段落、テーブルの前後、応用例文の各文の間、および箇条書き項目など、意味的な区切りには**必ず明示的に `<br>` または `<br><br>` タグを挿入し、適切な視覚的余白を維持すること**。物理改行の排除とHTML上の改行の省略を混同しないこと。
*   **HTML装飾のカラーパレット**:
    *   視認性を高めるため、文字色を変更する場合は以下のカラーコードに統一すること：
        *   重要情報・強調（格変化の語尾など）: `<span style="color:#d32f2f;">テキスト</span>` (濃い赤)
        *   補足・文法解説の紐付けなど: `<span style="color:#1976d2;">テキスト</span>` (濃い青)

## 2. 解説 (memo フィールド) の品質・構成基準

### 密度の高い学習要素の凝縮
*   **励まし文言の完全排除**: 「頑張りましょう」「〜への近道です」といったお世辞、挨拶、励まし、外部URLリンクなどの学習に直接関係のないノイズ要素は一切出力しない。純粋な学習データのみを出力すること。
*   **絵文字の制限**: 各セクションの識別子（🔍, 📊, 🔄, 📝）としてのみ絵文字を使用し、単語の意味（例：「本」を説明するために「📖」を使う）を視覚的に説明するための絵文字は絶対に使用しないこと。
*   **英語との比較**: 英語の語彙や文法（例: take/pass の使い分けなど）と比較することで理解が深まる場合に限り、文法解説の中で比較を補足として組み込んでもよい（独立したセクションにはしない）。
*   **カードの完全な独立性**: 各カードはランダムに出題されるため、「前回の〜と同様に」「前述の〜」といった、他のカードや特定の表示順序を前提とするメタ記述は一切出力しないこと。解説は常に1枚のカード内で完結させること。

### セクション構成
セクションの区切りには `<hr style="border: 0; border-top: 1px dashed #ccc; margin: 8px 0;">` を使用し、以下の構成で出力すること。

1.  **文法・単語の徹底解剖 (マーカー: `🔍`)**:
    *   ヘッダー見出しは、必ず **`<b>【文法・単語の徹底解剖 🔍】</b><br>`** の HTML フォーマットで開始すること（簡略表記 `🔍:` は絶対に使用禁止）。
    *   **オンラインレッスン講師・録音音声の消化方針**:
        *   担当講師は **アナスタシア先生 (Анастасия)**。
        *   **指導内容の真実性の徹底保持（創作・捏造の絶対禁止）**:
            *   レッスン録音やSTTで**実際にアナスタシア先生が口頭で解説・指導した事実がある項目に限り**、`<b>【💡 アナスタシア先生の指導ポイント】</b><br>` の見出しを使用すること。
            *   授業内で時間が足りず途中で終わった箇所、テキストの未学習部分（宿題・自習範囲）、または先生が特に言及しなかった文法・単語について解説する場合は、**無理に先生の指導として創作・捏造してはならない**。その場合は **`<b>【💡 学習の要点・実践アドバイス】</b><br>`**（または `【💡 学習の要点・実践アドバイス＆弱点徹底補強】`）とし、AIとしてユーザー様にとって真に最適・明快な文法解説や学習ポイントを正直かつ真摯に提供すること。
        *   **STT（音声認識）の解釈と日本語解説の徹底重視**: 先生の英語にはロシア語特有のアクセントや発音があり、STT（音声認識）の生テキストには誤認識（例: ユウスケ → Суки等）や不完全な文が含まれやすい。生の英語・ロシア語テキスト言及を無暗に貼り付けるのではなく、**アナスタシア先生が口頭で伝えたかった言語的ニュアンスや指導の核心を、明快でこなれた自然な日本語として噛み砕いて解説すること**。ユーザー様にとって「内容が日本語で完全にわかること」を最優先とする。
        *   **英語対比の積極的活用**: ロシア語はインド・ヨーロッパ語族として日本語よりも英語と文法構造や空間認識（前置詞・副詞、自他動詞・使役、体、語彙のニュアンス等）が遥かに近い。そのため、**日本語での解説を主軸としつつ、「英語で言えば〜（例: ahead / at the front / forward の違い、tire someone out 等）」という対比を積極的に組み込んで理解をブーストさせること**。
    *   `Russian` フィールドの文法構造、主要ターゲット単語、構文の意味などを解説する。
    *   動詞を解説する場合は、完了体/不完了体（体ペア）の区別および対応する相手の体を必ず明記すること。
    *   **体ペアの表記統一**: 解説の冒頭や対比の中で体ペアを示す際は、必ず **`不完了体 / 完了体`**（例：`знакомиться (不完了) / познакомиться (完了)`）の表記順序で対として統一して記述すること。
    *   **移動動詞の定・不定対比**: 移動動詞（例: ездить/ехать等）を扱う場合は、定動詞（一方向・具体的進行）と不定動詞（往復・複数回・習慣・能力）の区別および文脈での選択理由を明確に解説すること。
    *   **構文・副詞表現のバリエーション展開**: 文中に含まれる重要構文や副詞表現（例：否定、強調、比較、時間など）を解説する際は、品詞の説明にとどまらず、**実用的なバリエーションや関連する発展表現・パターン（例：`почти не`（ほとんど〜ない）に対する `почти никогда не`（ほとんど決して〜ない）など）を必ず1つ以上添えて解説すること**。
2.  **変化表 (マーカー: `📊`)**:
    *   ヘッダー見出しは、必ず **`<b>【変化表 📊】</b><br>`** の HTML フォーマットで開始すること。
    *   **折りたたみ（トグル）必須**: カード裏面の縦長化を防ぐため、変化表全体は必ず **`<details style="margin: 3px 0;"><summary style="cursor:pointer; color:#1976d2; font-weight:bold;">📊 活用表（または格変化表）を表示/非表示 (タップで開閉)</summary>... </details>`** の HTML5 折りたたみタグで囲み、デフォルト非表示にすること。
    *   不規則変化のほか、判断に迷うものや学習上の重要度が高い変化（軟変化の名詞、動詞の活用、形容詞の短尾形変化、数詞の変化など）が含まれている場合は、積極的に HTML テーブルで変化表を掲載すること。
    *   **一目でわかる6行対比表 / 3行2列コンパクト表示**: 動詞の活用変化表を掲載する際は、スペースを節約するための省略表記（例：`-ешь / -ет` など）は混乱を招くため一切使用せず、フルスペルで記述すること。また、縦方向の幅を抑えるため可能であれば **3行×2列（左: 単数 я/ты/он, 右: 複数 мы/вы/они）** のコンパクト対比レイアウトを採用すること。
    *   テーブルのスタイルは `GeminiAPITest` に準拠し、以下を適用する：
        *   `<table style="border-collapse:collapse; width:100%; border:1px solid #ccc; font-size:0.88em; margin-top:4px;">`
        *   行の背景色はヘッダーおよび偶数行に `style="background-color:#f2f2f2;"` を適用し、奇数行は通常背景とすること。
        *   各セルには `style="border:1px solid #ccc; padding:3px;"` を適用すること。
3.  **語彙ネットワーク (マーカー: `🔄`)**:
    *   ヘッダー見出しは、必ず **`<b>【語彙ネットワーク 🔄】</b><br>`** の HTML フォーマットで開始すること。
    *   🤝 **類似語**、⚔️ **反意語**、🔗 **関連語** をそれぞれ提示する。単語の表記だけでなく、意味や注意すべき格支配（例: 〜を望む/生格支配）などの情報を必ず添えること。
    *   **適切な難易度アジャスト（B1/2級ターゲット）**: 提示する類似語・反意語・関連語は, 難解すぎる文語・極めて稀な語彙（B2/C1以上）は避け, **ロシア語検定2級およびCEFR B1レベルで頻出の実用的な語彙（例：`осознавать`（認識する/不完了）など）を優先的に提示すること**。
    *   **文化的・実用的な関連語の採用**: ロシアの生活や文化（例: дача（別荘）など）に根ざした実用性の高い重要語彙を積極的に含め、必要に応じてその格支配（例: на дачу/на даче）も明記すること。
    *   **格変化の対称性・バランス**: 本文に出てくる特定の格変化語や、性別で形が分かれるペア名詞（例：翻訳者の男女ペアなど）を挙げる際は、関連語で片方だけを適当に挙げず、**両方の変化パターン（特にB1/2級で間違いやすい語尾変化）に対称的に言及し、バランスの良い解説にすること**。
    *   ※ HTMLとして出力する際は、`<ul>`や`<li>`などのブロック要素を使用せず、各語彙を `<br>` で区切ってインライン表示するか、タグの間に物理改行を含めずに1行で出力すること。
4.  **応用例文 (マーカー: `📝`)**:
    *   ヘッダー見出しは、必ず **`<b>【応用例文 📝】</b><br>`** の HTML フォーマットで開始すること。
    *   トピックに合致した、正しく自然なロシア語例文（アクセント記号なし）と日本語訳のペアを必ず2つ提示すること。
    *   **例文のモチーフ・世界観の原則**:
        1. **固定メインペルソナ（2大ヒロイン）の積極的活用**:
           - 🎹 **Алёна (アリョーナ)**: 才能あふれる若きロシア人ピアニスト（美貌と表現力を備える）。
           - 🎼 **Екатерина (エカテリーナ)**: モスクワ音楽院の学生（知性と美しさを兼ね備える）。
           - ※ 2人とも非常に魅力的で美しい人物という共有設定のため、文中で毎回不自然に `красивая` をつける必要はない。自然な日常や練習・リサイタルの文脈を描くこと。
        2. **ロシア人のリアルな日常生活**（カフェ、街歩き、地下鉄、ダチャ、四季の生活など）
        3. **モスクワ音楽院・ロシアピアノ音楽業界・クラシック音楽**（コンクール、リサイタル、練習、チャイコフスキー等）
        4. **サブ登場人物**: 必要に応じて Anna, Sofia, Polina などのロシア女性名も補助的に使用可。
    *   **難易度補足（B1以上の語彙への注記）**: 万が一例文内に難解な語彙・専門用語（CEFR B1以上など）が含まれた場合は、日本語訳の中にカッコ書き（例: `(*консерватория: 音楽院)` や `(*интерпретация: 解釈)`）でその単語の意味をさりげなく添えること。
    *   **例文の番号付けと強制改行**: 2つの例文は必ず以下のフォーマットで出力し、例文①と②の間には必ず空行を作るため **`<br><br>`** を挿入すること。例文が改行なしで横並びになったり繋がったりしないよう、改行位置を徹底すること。
        *   `① [ロシア語文１]<br>([日本語訳１])<br><br>② [ロシア語文２]<br>([日本語訳２])`
    *   例文内のターゲットとなる語彙は `<b>` タグで太字にすること（Markdown の `**` は絶対に使用しないこと）。

## 3. 厳格な自己チェックルール (品質保持)

カードの生成時および Anki への登録前に、以下のチェック項目を厳密に検証し、1つでも違反がある場合は再生成を行うこと。

*   [ ] **アクセント記号排除**: ロシア語テキストおよび解説内にアクセント記号（`\u0301`）が混入していないか。（※「е」の上のトレマ「ё」は標準文字のため維持するが、アクセント記号は完全に排除すること。）
*   [ ] **他言語の混入チェック**: 意図した英語比較（例: `英: take`）以外の不要な英語・他言語（ラテンアルファベットによるロシア語の発音転写表記など）が、日本語訳や解説内に混入していないか。ロシア語の解説は必ずキリル文字のまま記述されているか。
*   [ ] **HTMLタグの整合性**: 開始タグ（`<b>`, `<table>`, `<tr>`, `<td>`）と終了タグの対応が正しく一致しているか。テーブル内に空のセル（`<td></td>`）がないか。
*   [ ] **物理改行の排除とHTML改行の確保**: HTML実データ内に物理改行（`\n`）が含まれておらず、すべて1行にフラット化されているか。かつ、テキストが詰まりすぎて読みづらくならないよう、セクション境界、例文間、段落の区切り等に必要な `<br>` または `<br><br>` タグが十分に挿入されているか。
*   [ ] **絵文字ルール準拠**: セクションのヘッダーアイコン（🔍, 📊, 🔄, 📝）および語彙ネットワーク（🤝, ⚔️, 🔗）以外の場所で、単語の意味を絵文字で表す違反がないか。
*   [ ] **体ペアの明記**: 動詞を解説する場合、不完了体・完了体の別および対応するペアが漏れなく記載されているか。またその表記順序（不完了体 / 完了体）が統一されているか。
*   [ ] **カラーマークの適正化**: 格変化の語尾などの重要箇所が、指定カラー（濃い赤 `#d32f2f`）で正しくマークされているか。
*   [ ] **メタテキストの排除**: 「変化表を以下に示します」「類似語は〜です」のような、ルールに基づいた出力を言い訳・説明する不要なテキスト（メタ情報）が排除されているか。
